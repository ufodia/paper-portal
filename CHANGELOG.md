# Changelog

Entries describe source versions, not a hosted service or package publication.

## 0.1.0

Initial browser-local studio and independent player:

- Printable ArUco card deck with labels and colors.
- Authored visible, hidden, order and rotation stages with four scene presets.
- Explicit real-camera input and a clearly labelled simulator.
- Temporal progress with witness-based hiding and stale-observation resets.
- Project JSON, A4 card output and an embedded-runtime HTML player.
- Tracked standalone-player build, automated checks and English documentation.

Physical camera, print and lighting conditions require manual verification. Simulator and synthetic-frame tests have a narrower scope.
